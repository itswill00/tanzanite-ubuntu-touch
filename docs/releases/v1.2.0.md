Ubuntu Touch 24.04 (Noble) / Halium 12 for the **Xiaomi Redmi Note 14 4G** (`tanzanite`, MediaTek Helio G99 / MT6789).

Base-OS refresh, the audio fixes, and a kernel-base change.

> **Status:** built and assembled from this repository. Not flashed to hardware by this build;
> see [Caveats](#caveats).

## Changed

### Base rootfs: 20.04 (Focal) → 24.04-2.x (Noble)

The port was pinned to the Focal rootfs, two release series behind what UBports ships today. It now
tracks **24.04-2.x (Noble)** from the official
`ubuntu-touch-rootfs/job/ubports%2F24.04-2.x` (last stable) artifact.

`OTA_CHANNEL` is set to `24.04-2.x/arm64/android9plus/stable`. That channel exists in
`system-image.ubports.com/channels.json`; the `24.04/.../devel` form used upstream does not, and
would have left the device unable to fetch updates.

Installer naming moves `ut20.04` → `ut24.04`.

### Kernel base: personal fork → official Google ACK

The kernel came from `iprjkt/evernight-gki`, a device-specific GKI fork. It now builds from the
official Google **Android Common Kernel**, branch `android12-5.10-lts` (5.10.272).

ACK has no tanzanite definition, so the device pieces the fork carried are vendored here under
`kernel-overlay/` (`tanzanite_defconfig`, `tanzanite.dts`, `tanzanite-overlay.dts`) and copied into
the tree by `scripts/apply_kernel_overlay.sh`, which `scripts/build-all.sh` runs before configuring.
Release string: `5.10.272-tanzanite`.

### Audio

Only the fixes that were actually missing were taken from `iprjkt/tanzanite-halium`, chosen by
diffing the two trees rather than by commit subject:

- `libsixth.so` spinlock-crash patch and the missing `libsndcardparser.so` stub;
- `HYBRIS_LD_LIBRARY_PATH` extended with the overlay and vendor `lib64` directories so those
  libraries resolve;
- `aurisys_config.xml` SMARTPA downlink routed through `aurisys_demo`.

Commits already present here or superseded upstream (`0f9d016`, `be51bc0`, `65678a7`, `2c74d3a`, the
20.04-era `touch.pa`/policy commits, the reverted `[temp]` headphone modules) were left out.

## Caveats

- **Vendor modules.** `vendor_boot` ships the 207 MediaTek vendor `.ko` recovered from the 1.1.x
  installer. Their vermagic is `5.10.236-android12-9-…` while the kernel is `5.10.272-tanzanite`; the
  Halium module loader does not enforce the release string (the port already ran these modules on a
  5.10.269 kernel), so they load as-is and need no rebuild. `scripts/build-all.sh` fetches the set
  automatically when the tree has no `.ko`.
- **Missing fork patches.** ACK lacks the fork's out-of-tree Kconfig symbols (`CONFIG_TCP_CONG_BBR3`,
  `CONFIG_CPU_FREQ_GOV_REFLEX`, `CONFIG_CPU_FREQ_GOV_SCHEDHORIZON`, `CONFIG_PELT_UTIL_HALFLIFE_12`).
  `make tanzanite_defconfig` drops them with a warning; those features are absent.
- **Camera** still does not work.
